Comment ces sources ont-elles été choisies ?

La sélection privilégie les institutions compétentes, les rédactions identifiées et l’expertise des auteurs. Les flux sont testés avec le collecteur du site ; les échecs, doublons et sources anciennes sont écartés de l’import. Une vérification technique ne certifie pas chaque publication.

Une « source » est un flux, une rubrique, une émission ou une chaîne. Un éditeur peut en proposer plusieurs : le compteur de domaines permet de distinguer volume et diversité. La recherche évaluée, les prépublications, les opinions et les publications d’entreprises sont identifiées dans les fiches.

La provenance et les raisons de sélection sont consultables pour chaque source. Les contenus restent chez leurs éditeurs ; certains articles nécessitent un abonnement.
